1. Install Guide

This is a quick guide on installation, and updating.

1.1 Plugin Installation

1: Install From Wordpress Admin:

  1. Download zip file from codecanyon.
  2. Logged into wordpress admin panel.
  3. From menu navigate to plugins
  4. Click on Add New.
  5. Click Upload Plugin and then upload zip file that you hav downloaded from codecanyon. After installation click on Activate plugin.

 

2:  Install via FTP:

  1. Unzip the zip file that you have downloaded from codecanyon into you computer.
  2. Upload files via any FTP cient like Filezilla.
  3. After uploading all files logged in to wordpress admin panel.
  4. From menu navigate to Plugin and then click on Installed Plugins.
  5. Click on install button under then Addify – Private Shop Plugin.

2. User Guide

After activation of plugin you can see Private Shop in wordpress menu. Click on that. Now you can see a page on which all Settings of Private Shop are shown.

 

General Settings Tab

Here you can set background for the front end. you can select either image or colour. you can set opacity and Enable Disable Registration.

 

Access Control Setting Tabs

Choose what to privatize whole store or select items(product or categories). Enter the IPs that you want to exclude. Also allow or disallow google to crawl for SEO purpose.
